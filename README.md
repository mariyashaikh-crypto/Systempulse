### AI-Powered System Observability & Anomaly Detection Platform

> **SystemPulse** turns system metrics into actionable insights — helping developers monitor services, detect anomalies, understand root causes, and respond before small issues become incidents.

🌐 **Live Demo:** https://project-live-b2595.web.app  
💻 **GitHub:** https://github.com/mariyashaikh-crypto/Systempulse  
🎥 **YouTube:** https://youtu.be/ndZcmLerMjM

---

## 🚀 Core Features

- 📊 Real-time system monitoring
- 🚨 Anomaly & early-warning detection
- ⚠️ Risk and severity scoring
- 📈 Latency, CPU & memory tracking
- 🧠 Root-cause analysis
- 💡 Automatic explanations & recommended actions
- 📉 Historical metrics & trend analysis
- 💚 Service health monitoring
- 🛍️ Product-service monitoring
- 🌙 Professional dark-mode dashboard
- 📱 Responsive UI
- ☁️ Production deployment

🛠️ Tech Stack

Frontend: React • Vite • Tailwind CSS • Lucide Icons
Backend: Python • FastAPI • PostgreSQL
Deployment: Firebase Hosting • Render • GitHub

📁 Project Structure
Systempulse/
├── frontend/
├── demo-system/
├── systempulse/
├── .gitignore
└── README.md

Run Locally
git clone https://github.com/mariyashaikh-crypto/Systempulse.git
cd Systempulse/frontend
npm install
npm run dev

Production build:

npm run build


Keep production credentials and secrets out of GitHub.

☁️ Deployment

Frontend is deployed with Firebase Hosting and backend services are deployed separately.
